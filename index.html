No guitar at hand? Demo detunes are random; the true value shows under each string.

Strum, then pluck

Strum all open strings once and every string gets a reading. Then pluck any string on its own: Strumtune switches to that string automatically and gives a faster, finer reading while you turn the peg.

How it hears six strings

A 1.4-second spectrum is matched against where each string's fundamental and overtones should sit for the chosen tuning. Overtones that two strings share are explained by the string that owns them, so the rest can be measured independently.

Limits

A string within a few cents of another string's exact overtone (an octave or fifth above) can't be pulled apart in a strum; it shows ≈. Strum readings cover about ±60 cents; for a badly detuned string, pluck it alone.
